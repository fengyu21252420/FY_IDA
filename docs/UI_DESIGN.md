# FY_IDA UI 设计文档

更新时间：2026-06-23

界面代号：FY Classic 中文界面

目标：设计一个让 IDA 用户能快速上手的中文逆向分析工作台。界面采用传统 Windows 桌面工具风格，保留常见逆向分析工作流，但不复制 IDA Professional 的图标、专有配色、数据库格式、品牌元素或逐像素布局。

## 1. 设计原则

- 中文优先：菜单、窗口标题、按钮、提示、日志默认使用中文。
- 静态分析优先：第一屏重点服务 PE/x64 反汇编、函数列表、字符串、导入导出和 xref。
- 熟悉但自有：工作流接近传统逆向工具，视觉表达使用 FY_IDA 自己的配色、间距、图标和术语。
- 轻量高密度：界面以信息密度和可扫描性为主，不做营销式首页、不做大卡片欢迎页。
- 单人本地使用：不出现账号、云同步、团队协作、许可证入口。
- 浅色主题：第一版只做浅色经典主题。
- 稳定布局：常用窗口默认固定在左、中、右、底四个区域，用户后期可调整停靠。
- 低装饰：不使用渐变球、背景图、大面积插画或过度圆角。

## 2. 主窗口布局

默认布局：

```text
+--------------------------------------------------------------------------------+
| 菜单栏：文件 编辑 视图 分析 类型 脚本 工具 帮助                                  |
+--------------------------------------------------------------------------------+
| 工具栏：打开 保存 后退 前进 跳转 搜索 重新分析 函数图 伪代码                     |
+----------------------+----------------------------------------+----------------+
| 左侧导航区           | 中央工作区                             | 右侧信息区     |
| 函数                 | 反汇编 / 十六进制 / 伪代码 / 图视图    | 交叉引用       |
| 名称                 |                                        | 属性           |
| 字符串               |                                        | 局部类型       |
| 导入                 |                                        | 结构体         |
| 导出                 |                                        |                |
+----------------------+----------------------------------------+----------------+
| 底部面板：输出 搜索结果 Python 控制台 日志                                      |
+--------------------------------------------------------------------------------+
| 状态栏：当前地址 文件偏移 函数名 分析状态 项目状态                              |
+--------------------------------------------------------------------------------+
```

### 2.1 左侧导航区

默认宽度：260 px。

标签页：

- 函数
- 名称
- 字符串
- 导入
- 导出
- 段
- 书签

用途：

- 快速定位函数、符号、字符串和 PE 结构。
- 支持过滤框。
- 支持按地址、名称、大小、引用次数排序。
- 双击条目后中央工作区跳转到对应地址。

### 2.2 中央工作区

默认占据最大区域。

标签页类型：

- 反汇编
- 十六进制
- 伪代码
- 函数图
- 调用图
- IR 视图

用途：

- 反汇编是默认首页。
- 十六进制用于核对原始字节。
- 伪代码在反编译器阶段启用，前期可显示占位说明。
- 函数图显示当前函数 CFG。
- 调用图显示函数调用关系。
- IR 视图在反编译器阶段启用。

### 2.3 右侧信息区

默认宽度：320 px。

标签页：

- 交叉引用
- 属性
- 局部类型
- 结构体
- 注释

用途：

- 显示当前地址、函数、字符串、导入 API 的引用。
- 显示当前选中项的 VA/RVA/文件偏移、section、类型、名称。
- 编辑函数原型、结构体、enum、注释。

### 2.4 底部面板

默认高度：180 px。

标签页：

- 输出
- 搜索结果
- Python 控制台
- 日志
- 任务

用途：

- 输出自动分析进度。
- 展示搜索结果。
- 执行 Python 命令。
- 展示脚本和插件错误。
- 后续显示批量分析任务状态。

## 5. 反汇编视图

### 5.1 列结构

默认显示：

```text
地址              字节                 指令        操作数                 注释
140001000         48 89 5C 24 08       mov         [rsp+8], rbx
140001005         57                   push        rdi
140001006         48 83 EC 20          sub         rsp, 20h
```

列说明：

- 地址：VA。
- 字节：机器码字节，可配置隐藏。
- 指令：mnemonic。
- 操作数：格式化 operands。
- 注释：自动注释和用户注释。

### 5.2 行类型

- 函数头：显示函数名、地址、大小、引用数量。
- 基本块分隔：使用浅灰线条。
- 普通指令：单行显示。
- 跳转目标：显示标签。
- 数据项：显示 db/dw/dd/dq、字符串、指针。
- 导入引用：显示 DLL!API。
- 用户注释：优先显示。

### 5.3 颜色规范

浅色经典主题：

- 主背景：`#F7F7F4`
- 面板背景：`#FFFFFF`
- 面板边框：`#C8CDD2`
- 标题栏背景：`#E8EBEF`
- 普通文本：`#1F2328`
- 地址：`#5E6B78`
- 字节：`#8A6F3D`
- 指令助记符：`#143D73`
- 寄存器：`#005CC5`
- 立即数：`#6F42C1`
- 字符串：`#22863A`
- 注释：`#6A737D`
- 函数名 / 标签：`#005A9C`
- 导入 API：`#B31D28`
- 当前行：`#FFF3B0`
- 选中行：`#DDEBFF`
- 跳转高亮：`#B3D4FF`
- 错误：`#D73A49`
- 警告：`#B08800`

注意：这些是 FY_IDA 自有色值，不从 IDA 提取。

### 5.4 交互

- 单击：选中地址。
- 双击函数名/标签：跳转。
- 双击导入 API：跳到导入项或显示 xref。
- 右键：打开上下文菜单。
- 鼠标悬停地址：显示 VA/RVA/File Offset。
- 鼠标悬停 API：显示函数原型和所属 DLL。
- 鼠标悬停字符串：显示完整字符串。

## 6. 十六进制视图

布局：

```text
文件偏移 / VA      00 01 02 ... 0F        ASCII / UTF-16 预览
00001000          4D 5A 90 00 ...         MZ..
```

功能：

- 支持 VA/RVA/File Offset 切换。
- 支持同步当前反汇编地址。
- 支持选择字节范围。
- 支持复制 hex。
- 第一版不支持 patch bytes。

## 7. 函数图视图

用途：显示当前函数的 basic block 和跳转边。

节点内容：

- 首地址。
- 简短指令列表。
- 块内调用摘要。
- 块内关键字符串引用。

边类型：

- 条件真分支：绿色。
- 条件假分支：红色。
- 无条件跳转：蓝色。
- fallthrough：灰色。

交互：

- 双击节点跳到线性反汇编。
- 鼠标滚轮缩放。
- 拖动平移。
- Space 在线性反汇编和函数图之间切换。

## 8. 调用图视图

用途：显示函数之间调用关系。

节点：

- 函数名。
- 地址。
- 大小。
- 是否库函数。
- 是否导入 thunk。

边：

- caller -> callee。
- 可过滤库函数和 thunk。

第一版目标：

- 从当前函数向上游/下游展开。
- 支持深度限制。
- 支持搜索节点。

## 9. 快速跳转

快捷键：`G` 或 `Ctrl+G`。

输入支持：

- VA：`140001000`
- RVA：`rva:1000`
- 文件偏移：`file:400`
- 函数名：`decrypt_config`
- 导入 API：`CreateFileW`
- 字符串关键词：`cmd.exe`

结果显示：

- 分类：地址、函数、名称、字符串、导入、导出。
- 上下键选择，Enter 跳转。

## 10. 搜索

## 14. 空状态设计

启动后如果没有打开文件：

- 中央显示“打开文件”按钮。
- 下方显示最近项目列表。
- 不显示营销介绍。
- 不显示大面积装饰图。

空状态文案：

```text
尚未打开文件
打开 PE 文件或 Raw Binary 开始分析
```

按钮：

- 打开文件
- 打开 Raw Binary
- 打开项目

## 15. 状态栏

状态栏从左到右：

- 当前地址：`VA 140001000`
- RVA：`RVA 00001000`
- 文件偏移：`FO 00000400`
- 当前函数：`mainCRTStartup`
- 分析状态：`分析完成` / `分析中` / `有警告`
- 项目状态：`已保存` / `未保存`

## 17. 第一版验收标准

- 程序启动后显示中文菜单、工具栏、左右底部面板和状态栏。
- 默认布局稳定，不出现控件重叠。
- 打开文件入口存在，即使 loader 未完成也能显示错误提示。
- 面板标题、菜单和按钮都使用中文。
- 反汇编视图能显示占位行或真实指令行。
- 左侧列表和中央视图可以通过点击进行跳转。
- 底部输出窗口能显示分析日志。
- `G` 可以打开快速跳转框。
- `Ctrl+F` 可以打开搜索框。
- 所有窗口保持浅色经典工具风格。

## 18. 后续可配置项

后续在“选项”中支持：

- 显示 / 隐藏机器码字节列。
- 地址显示为 VA / RVA / File Offset。
- 字体大小。
- 等宽字体选择。
- 自动保存间隔。
- 默认打开目录。
- 最近文件数量。
- 是否自动开始分析。
- 是否折叠库函数。

## 19. 不做项

第一版不做：

- 暗色主题。
- 动态调试窗口。
- Patch bytes。
- 团队协作入口。
- 账号登录。
- 云同步。
- 插件市场。
- 逐像素复制其他商业软件界面。
